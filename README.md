# 钟山景区车辆通行图

根据《钟山风景名胜区交通优化提升措施的通告》（中陵规〔2025〕1号）制作的交互式道路通行参考图。

## 数据说明

- 管控规则：南京市中山陵园管理局 2025 年 9 月 25 日正式通告，自 2025 年 10 月 1 日起施行。
- 地理底图和道路线位：基于 OpenStreetMap（ODbL）数据生成，并随网页内置发布；不加载境外地图图块或外部地图脚本。底图快照日期为 2026-09-04，覆盖钟山及周边（32.015–32.115°N，118.785–118.925°E）。
- 灵谷寺西路在开放地图中没有完整路名线位，网页中以虚线示意并明确标注。
- 公安机关可根据道路与流量动态管控，实际通行以现场标志和人员指挥为准。
- 地图在 HTML 首屏直接输出 SVG，脚本延迟或禁用时仍显示道路；脚本启用后支持滚轮、按钮、键盘、拖动及双指缩放。
- 缩放分为三级：总览显示山林、水面、主干路及周边街道；中层增加支路、步道、地铁站；近景增加建筑轮廓、台阶与路口。地名自动避让，底图与管制线使用同一坐标系。
- 灰色背景街道和细虚线步道仅用于地理定位，不代表允许电动自行车或机动车通行。内置区域之外不提供地图，也不提供实时导航。
- 底图衍生数据可从 `public/data/basemap.json` 下载，按 ODbL 1.0 提供，详见 `public/data/LICENSE.md`。用 `node scripts/build-basemap.cjs <Overpass-out-geom.json>` 可重新生成。
- GitHub Pages 发布前自动测试地图显示、时段/车型切换、三级缩放、拖动、双指缩放、移动端布局和无脚本首屏。
- 配色：蓝色表示可骑行但机动车受限，绿色表示通告未作特别限制，红色表示禁止通行，黄色表示预约条件通行。管控时段外，没有明确专项限制的路段显示绿色。
- 拖动和连续缩放通过逐帧合并的合成层变换处理；停下后更新清晰线位与地名，长距离拖动提前补足周边画面。`scripts/map-performance.cjs` 提供相同浏览器下的可重复拖动性能对比。

## 本地运行

```bash
npm install
npm run dev
```
